Results

Pipeline Run Results

The pipeline ran successfully. However, a large fraction of tiles were skipped due to being over the nodata threshold (30%) — most of the downloaded area contained empty/transparent border pixels with no actual forest imagery.

Most tiles had nodata ratio = 1.0 (100% empty). This is expected given the rectangular download area — real forest coverage is non-rectangular and leaves large border gaps.
Pipeline validated end-to-end on real GBA data. Detection model ran on all non-empty tiles. GPU utilization confirmed at 93% during Step 3 predictions.

Tile Status

Majority skipped — nodata ratio exceeded 0.3 threshold. Border tiles from rectangular WMS crop have no actual imagery.

Key Learnings

Need tighter polygon-bounded crop instead of rectangular BBOX, or a higher-resolution source to reduce nodata percentage in each tile.

Next Step

Use actual forest boundary polygon to crop imagery before tiling, reducing skipped tiles significantly.

Development 03

Guest Login on Frontend

Added a guest login flow to the frontend so the pipeline remains accessible without requiring Google SSO credentials, while keeping the full auth path ready for when a Client ID is configured.

  • Auth gate (landing page) always shown on load
  • "Continue as Guest" button — bypasses SSO, enters pipeline directly
  • Google login button shown only when GOOGLE_CLIENT_ID is set
  • Both flows coexist — no backend changes required
  • Guest sessions not attributed to any account
Pipeline is now usable by any team member without requiring Google OAuth setup.
